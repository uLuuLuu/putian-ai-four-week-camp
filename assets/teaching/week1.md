# Week1 教学文件 · 把 WorkBuddy 装进你的电脑

## 目标
装一个能真的动手干活的 AI 同事：把工具装好、让它认识你、现场跑通一个任务。

- 预计用时：约 25 分钟
- 前置要求：无，零门槛
- 本周产出：1 个能跑通任务的 WorkBuddy
- 难度：★☆☆☆☆

> 很多同学不是不会用 AI，是打开对话框之后不知道说什么。这一周的目标很简单：把工具装好、让它认识你、现场跑通一个任务。装完这一步，你就跨过了最难的那个门槛。

## 分步指引

1. **下载安装**：打开官网 [workbuddy.cn](https://www.workbuddy.cn/)，往下拉到页面最底部的「立即下载」。Windows 只有一个包直接下；Mac 有两个包，选错会闪退——点苹果菜单 → 关于本机 → 看「芯片」：Apple M 系列选 `Mac ARM64`，Intel Core 选 `Mac x64`。Win 弹蓝色警告点「更多信息 → 仍要运行」；Mac 提示开发者不明就去「系统设置 → 隐私与安全性」点「仍要打开」。
2. **微信扫码登录**：新用户有限时免费的体验版额度，这几周的练习量完全够用，先不用考虑付费。
3. **选一个模型**：在输入框下方找「模型选择」，不知道选哪个就问它「当前推荐哪个模型做内容生成」。
4. **建工作空间（别跳过）**：自己动手建一个文件夹当它的"工位"（Win：`D:\AI工作区`；Mac：`~/Documents/AI工作区`），里面再建 `01-原始资料` / `02-我的项目` / `03-产出`。然后在输入框左下角点「选择工作空间」选中它。不选的话，它生成的文件会散落在默认目录，你下次根本找不到。
5. **验证工作空间**：问它"你现在的工作空间是哪个目录？把这个目录下的文件列给我看"，报出的路径要和你建的文件夹**对得上**。对不上就是没选上。
6. **五步初始化**：让它认识你（专业/年级/在忙什么）→ 挑一个语气 → 装 1 个技能 → 连上你的数据线。全都是"对着它说一句话"，不用点设置菜单。
7. **跑通第一个任务**：让它整理你的乱文件夹、做一份期末复习计划，或者建一个每天早上自动推送信息的任务。
8. **记住一件事**：WorkBuddy 是跑在**你电脑上**的本地应用，电脑关机 = 定时任务不执行。

## 验收清单
- [ ] 能正常打开 WorkBuddy，微信扫码登录成功
- [ ] 选好了模型（不是默认的 Auto 状态）
- [ ] 自己建了 AI工作区 文件夹，并设成了工作空间
- [ ] 让它报过一次工作空间路径，和你文件夹的实际路径对得上
- [ ] 告诉过它你的专业、年级、正在忙的事
- [ ] 至少装上了 1 个技能
- [ ] 跑通了一个任务，右侧结果区拿到了真实文件
- [ ] 知道「电脑关机定时任务不跑」这件事
