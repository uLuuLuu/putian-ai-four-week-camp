# Week3 教学文件 · 做你的第一个 Skill

## 目标
把一件重复的事口述给 AI，让它变成可复用、可分享的技能。

- 预计用时：约 40 分钟
- 前置要求：完成第 2 周（有知识库效果更好）
- 本周产出：1 个可复用、可分享的 Skill
- 难度：★★★☆☆

## 分步指引

1. **先筛选，别急着动手**：用三个标准过一遍——会重复（做过 ≥3 次）、有套路（每次步骤差不多）、有明确输出（会产出具体东西）。三条全中才值得做。
2. **口述流程**：不用学怎么写 Skill，你只要会"说"。像带新人一样把步骤讲出来，重点是**「你最在意的三条规矩」**这一栏千万别空——它是防止 AI 偷懒编造的护栏。
3. **生成 Skill**：确认它复述的理解无误后，让它生成 Skill 文件、写入你的规矩、告诉你安装路径、给你 3 个调用示例。
4. **立刻试跑**：用真实素材跑一次，并让它自己交代「哪一步是猜的」。第一次不完美很正常。
5. **迭代改 3 轮**：不改代码，只改说法。每次改完用同一个输入重跑对比。改 2–3 次基本就稳了。
6. **导出分享**：Skill 是可以导出成文件夹发给同学的——这是你第一个能"传下去"的 AI 资产。

## 验收清单
- [ ] 能用自己的话说清 Skill 是什么
- [ ] 用三个标准筛出了要做的那件事
- [ ] 把流程完整口述给了 WorkBuddy，并确认了它的复述
- [ ] 给出了至少 3 条"最在意的规矩"
- [ ] Skill 生成成功，知道它装在哪
- [ ] 用真实素材试跑过至少 1 次
- [ ] 迭代修改过至少 1 轮，并对比了前后差别
- [ ] 导出了 Skill 文件夹，准备分享
