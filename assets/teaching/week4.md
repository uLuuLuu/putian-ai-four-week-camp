# Week4 教学文件 · 做个人网页并上线

## 目标
把前三周攒的东西装进橱窗，拿到一个 https 链接写进简历。

- 预计用时：约 60 分钟
- 前置要求：完成第 2、3 周（没做知识库也有替代方案）
- 本周产出：1 个公网可访问的个人主页
- 难度：★★★★☆

## 分步指引

1. **★ 先让 AI 读你的知识库**：第 2 周那 40 分钟在这里兑现。4 个模块的内容（我是谁 / 我会什么 / 我做过什么 / 怎么找我）**全是私人知识**——别自己硬憋，让 WorkBuddy 读你的知识页，从你自己的经历和偏好里起草。**没做知识库的话，就用"让 AI 当面试官反问你"这个替代方案。**
2. **先定内容，别一上来就让 AI 做**：这是最常见的失败方式。先拿到「网页内容清单」，确认 4 个模块都有内容，再动手。
3. **用标准四文件结构生成**：`index.html`（内容）+ `style.css`（样式）+ `script.js`（交互）+ `assets/`（图片图标）。要求它只用**相对路径**，所有资源双击就能打开。
4. **本地打开看，改到满意**：双击 index.html 就能看。改配色、改字号、改布局，全程只用嘴说。想看手机效果按 F12 切手机预览。
5. **让它一次给 2 个风格版本**：深色科技风 vs 浅色简约风，放两个文件夹对比，选一个。
6. **部署上线**：最简单是直接让它一键部署给你公网链接；想练手可以选 GitHub Pages。
7. **换设备验证**：把链接发给一个同学，让他在自己手机上打开——路径问题只有换设备才会暴露。

## 验收清单
- [ ] 有「网页内容清单」，4 个模块都有内容
- [ ] （做了知识库的同学）内容是 AI 读你的知识页生成的，不是你硬憋的
- [ ] 目录结构是 index.html + style.css + script.js + assets/
- [ ] 所有资源引用都是相对路径，没有 C:\ 或 /Users/ 开头的
- [ ] 本地双击 index.html 能正常打开，样式和图片都在
- [ ] 手机上打开也正常（响应式生效）
- [ ] 至少改过 1 轮，对比了不同风格
- [ ] 拿到公网链接，并且在别人的手机上打开验证过
- [ ] 没放手机号、身份证等隐私信息
- [ ] 已经把链接写进简历或个人介绍里
