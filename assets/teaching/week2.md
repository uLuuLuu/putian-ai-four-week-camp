# Week2 教学文件 · 搭一个会自己长大的知识库

## 目标
用 ima 建知识库，让 WorkBuddy 把你的资料编译成"会长大"的网络。

- 预计用时：约 30 分钟（收）+ 约 40 分钟（编译）
- 前置要求：完成第 1 周
- 本周产出：1 个能查的知识库 + 1 个能自己长大的知识网络
- 难度：★★☆☆☆

## 分步指引

1. **【第一部分】装 ima**：去 [ima.qq.com](https://ima.qq.com/) 下载客户端。四个入口数据自动同步，建议「电脑客户端 + 微信小程序」两个就够——小程序负责随手收，客户端负责整理。
2. **建知识库 + 定结构**：改个好名字，然后**手动建 3 个文件夹**：`01-原始素材` / `02-知识页` / `03-我的产出`。这 3 个对应「存储 / 处理 / 思考」，**别建超过 3 个**。
3. **让 WorkBuddy 帮你"备菜"**：先扫描你本地那堆乱文件，去重、合并、给命名建议，生成一份《导入清单》——你再照着清单往 ima 里拖。
4. **投喂**：六种收集方式——本地文件拖拽 / 微信群文件 / 公众号文章一键存 / 网页链接 / 图片（能认字）/ 录音（自动转文字）。**别一次投 200 个，先投 5 份。**
5. **学会用 @ 提问**：提问时带上 `@你的知识库名`，它才会只从你存的资料里找答案。
6. **【第二部分】打通 WorkBuddy × ima**：这是本周**唯一的硬门槛**。在连接器管理里找到 ima 点「信任」授权；要 Key 就去 [ima.qq.com/agent-interface](https://ima.qq.com/agent-interface) 拿。连通后发「列出我的所有知识库」验证。
7. **让 AI 采访你**：冷启动最爽的一步——你不需要写任何东西，它一次问一个问题，把你的私人知识"问"出来。通常 15–20 个问题。
8. **让它设计并搭建骨架**：基于采访结果规划知识页、子分类、**命名规则**、以及「总索引」和「操作日志」两个特殊页。**先看方案再执行。**
9. **跑第一次"摄入"**：说一句「检查有哪些没处理过的素材，执行一次摄入」，看它通读、建摘要页、更新相关页面、标注矛盾、建立引用、更新索引、追加日志——**一份素材牵动多个页面**。
10. **同一个问题问两边**：先去 ima 原生问答问，再让 WorkBuddy 读知识页答。**对比两边的回答，你就亲眼看到了"检索"和"编译"的区别。**
